Catch v0.7 導入手順

1. Android Studioで実行中のCatchを停止します。
2. このZIPを展開し、入っている lib / android フォルダと pubspec.yaml を
   次のフォルダへ上書きコピーします。

   C:\Users\gosho\AndroidStudioProjects\catch_app

3. Android StudioのTerminalで次を順番に実行します。

   flutter clean
   flutter pub get

4. 実行端末を Medium Phone API 36.1 にして、▶で起動します。
5. Androidに通知の許可を聞かれたら「許可」を選びます。
6. Catchの「設定」→「テスト通知を送る」で通知を確認します。

今回の変更
- ウォッチを検索チャット形式へ変更
- 右スワイプで監視中チャットの履歴を表示
- 同じテーマの新着を同じ会話へ継続追加
- 記事内の日付候補を予定・通知へ保存
- 画面からCatchで、Teams以外の画面も画像保存なしで読み取り、タスク・カレンダー・通知へ登録
- 日本語対応の端末内AIで情報元の日時を抽出。時刻不明なら23:59で勝手に保存しない
- これまで保存したタスク、予定、ウォッチ、設定は引き続き読み込み

注意
- 通知のテストはWindows版ではなくAndroidエミュレータで行ってください。
- 初回の画面取り込み時だけ「他のアプリの上に表示」と画面共有を許可してください。エミュレータではChromeの日時が書かれたページでも試せます。
- 初回のAI日時解析時だけGoogle ML Kitのモデルをダウンロードします。APIキーやカードは不要です。
- 読み取った画面画像はメモリだけで処理し、写真フォルダへ保存しません。
